# TNLauncher

## Commits

Format: `type(scope): description`

- **type**: `feature` (new functionality), `refactor` (code change without new behavior, incl. performance), `delete` (removing code or features).
- **scope**: `tauri` (src-tauri, Rust backend) or `frontend` (src, React). A change touching both is split into one commit per scope.
- **description**: imperative, lowercase, no trailing period, e.g. `feature(frontend): add modpack import dialog`. Details go in the body.
